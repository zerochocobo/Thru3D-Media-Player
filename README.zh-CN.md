# Thru3D Media Player

[English](README.md) · [更新日志](CHANGELOG.zh-CN.md) · [English changelog](CHANGELOG.md)

面向 Meta Quest 和 PICO 的独立 VR/MR 媒体播放器，可直接在头显中观看视频和照片、浏览媒体库，并使用支持内容的透视与立体效果。

当前源码版本：**0.16.1**，Android versionCode **55**；另提供实验性的标准 OpenXR Android 导出目标。

最低兼容目标为 **Quest 2、PICO Neo3**。源码和构建兼容不等于所有机型的性能、显示及交互均已实机验收。

## 功能

- 扩展静态／动态图片与相机RAW，Emby／Jellyfin相册看图；见[格式与解码范围](docs/IMAGE_FORMAT_SUPPORT_CN.md)。
- 浏览器区域聚焦、头显内网盘登录窗口、PGS换色、可选VR刻度和带署名的银河全景。
- 视频3D最高200%增强、透视保留背景及切换模式保留画面。
- ZipDepth视频2D转3D、补洞填充／边缘拉伸、线性强度和50%推荐标记，照片深度独立；见[模型准备](docs/MODELS.md)。
- 兼容平面立体视频的人像透视、照片透视连续切图及更稳定的立体照片过渡。
- 独立B站“播放（Beta）”，使用当前登录网页会话和实际媒体请求，仍受账号、网站及格式限制。
- 兼容的未加密DVD ISO、标题／章节选择及手柄射线原盘菜单，见[光盘播放范围](docs/BLURAY.md)。
- 对等浏览器窗口（高性能档最多4个）、精选／书签新标签页、按站点开启的媒体嗅探与来源页面内的接管状态；不兼容／受保护内容继续网页播放。
- 兼容的平面文字字幕独立合成图层、沉浸画面对齐引导及更直观的画中画缩放反馈。
- 内置网页浏览器（Beta），最多4标签，高性能档最多4窗口／低性能档2窗口、浮动／影院显示、书签历史及可选同网远程管理；支持范围内网页视频可全屏自动／手动交给播放器，见[浏览器与渠道范围](docs/WEB_BROWSER.md)。
- 普通平面视频立体人像透视，独立大小／距离记忆及可选精细层次，见[人像适用范围](docs/VIDEO_PORTRAIT.md)。
- 外挂字幕自动编码检测／逐字幕覆盖，VR握持调节及±10%水平双目对齐。

- 全片原声／双语字幕预生成队列，支持暂停、继续、优先处理与重试；缓存遵循逐片隐私策略，见[字幕任务](docs/LIVE_SUBTITLES.md)。
- Emby／Jellyfin影片详情中选择媒体版本，各文件独立记忆进度与观看设置。
- AI人像透视省内存模式，以及手动保存／临时Wi-Fi分享诊断日志；见[运行设置](docs/RUNTIME_SETTINGS.md)。

- 视频实时字幕：本地识别中／英／日对白，可选联网翻译、双语显示，按隐私设置复用逐片识别缓存；[适用范围与准备延迟](docs/LIVE_SUBTITLES.md)。

- 本地／网盘PDF与杂志漫画双页，支持从右向左和画中画翻页，见[文档范围](docs/PDF_READING.md)。
- 漫画朗读／翻译：停留朗读、译文覆盖及现有音色，OCR与19种目标语言受[网络／模型范围](docs/COMIC_READING.md)限制。
- 已保存循环导出、平面／VR现场录制及支持范围内的画中画合成，见[捕获输出](docs/CAPTURE.md)。

- 局域网 DLNA 视频投屏接收，手动开启并确认替换正在观看的媒体，见[接收范围](docs/DLNA_CASTING.md)。
- 无需字幕的自定义声音取样、语音候选与行内裁剪；[VAD及声音资源](docs/MODELS.md)另行准备。

- 统一书签／A–B循环管理，支持从书签选择范围和点击时间跳转。
- 蓝光标题切换及支持范围内的非3D HDMV射线菜单；BD-J仅识别，见[蓝光范围](docs/BLURAY.md)。
- 支持兼容加密格式的压缩漫画浏览与私有密码关联，见[压缩漫画](docs/ARCHIVE_COMICS.md)。
- 新用户默认巨幕影院，支持Debug／Release、影片驱动溢光、双套烘焙灯光、座位记忆与移动；已有背景保持，照片独立默认贝尔法斯特夕阳；[影院生成](docs/EXPERIMENTAL_CINEMA.md)及[手柄模型准备](docs/CONTROLLER_ASSETS.md)所需资源另行提供。

- 最多三个共享视频帧的画中画窗口，支持区域放大、独立摆放与静态图片窗口，见[画中画说明](docs/PICTURE_IN_PICTURE.md)。
- 徒手腕表显示时间／电量／进度，并提供投影播放控制。
- 目录排序与按筛选记忆的浏览位置，统一跟随历史隐私；按网盘能力提供页数设置及显式全部载入。
- 控制栏空间锁与透明度、兼容180°图片背景及Emby详情底图。
- 播放刷新率默认72 Hz省电档，也可选最高90 Hz或最高120 Hz；保留已有用户的选择，按设备能力生效，AI／深度模式保留受限策略。

- 视频和照片：平面、180°、360°，单目和左右立体。
- 支持的 180° 视频人物抠像与透视合成。
- 平面单目视频、照片的深度 2D→3D 显示。
- 本地文件、SMB、WebDAV、DLNA、媒体服务器，以及115、百度、阿里云盘、夸克和OneDrive连接。
- 音轨、文字字幕与平面视频PGS位图字幕、0.25×～3×倍速/音高补偿和逐文件观看偏好。
- Plex手机/电脑配对、片库浏览与原片播放。
- 兼容设备上的Dolby Vision Profile 5颜色处理；不泛化全部格式、杜比认证或原生HDR。
- 视频旋转、平面距离/大小/曲率及文字字幕字号/位置；画面旋转时字幕保持正立。
- 手柄射线/扳机选择、手部交互及中英日界面。
- 持久化时间点书签、最近播放源帧预览、分页浏览。
- 手部/手柄可视化、锐度及平面屏幕调整。
- VR 内账号管理和内嵌网页登录、速度优先与精确跳转。
- 沉浸式图片展示、捏合横拖切图、相邻图片预加载和3D缓存；图片立体强度最高200%。
- 媒体服务器分区、筛选、详情和连续分页；收藏与外挂字幕取决于服务器能力，支持手动添加DLNA地址。
- 图片距离/大小调整、按实际显示尺寸计算的2～8倍独立放大镜，以及按来源能力提供的文件管理。
- 支持设备上的高效合成层视频／照片显示与高清菜单，按显示能力回退；慢帧时保留菜单合成层清晰度。
- 场景化自定义按键、组合键、冲突互换、界面移动和手势动画说明。
- 每个视频的字幕／音轨选择记忆、五种文字字幕配色及固定位置的沉浸立体字幕。
- 3D／音量双击快捷开关、跨启动保留音量和静音状态、完整文件名悬浮提示。
- 支持范围内的未加密普通蓝光／MVC 3D ISO 主影片直接播放（含兼容的多片段标题），支持音轨与跳转，详见 [蓝光支持范围](docs/BLURAY.md)。
- 按网盘能力提供关键词搜索、范围与媒体类型筛选，不后台扫描全盘。
- Emby／Jellyfin 海报墙、演员关联、详情多图与多段影片选择、首页最近打开列表。
- 滑块单项重置、调色本页重置，以及原色／暖色／冷色／自定义四种调色选择。
- 普通目录列表／图标浏览、Emby/Jellyfin三视图与大小偏好、完整简介和可滚动详情。
- 播放中紧凑／完整媒体库切换，保留播放控制栏及联动位置。
- 字幕同步±10秒／0.1秒精调与逐片记忆、自动同名字幕及平面PGS大小／位置调整。
- 支持范围内的STRM链接播放、远程加载阶段／实际读速和可查看的错误详情。
- 独立超采样与锐度设置、固定距离握持移动及同手摇杆推拉。
- 支持设备上的高效调色：兼容的曝光、对比度和色温调整保持合成层显示；伽马／饱和度等选项提供性能悬浮提示。
- 控制栏上方的紧凑播放设置、调色及立体观看弹窗，调整时保留播放控制；射线在菜单外按扳机关闭菜单。
- 文件大小与播放位置同时显示，媒体服务器卡片保留已有年份／总时长及观看状态。

- 外挂字幕恢复、同名／界面语言自动匹配，手动及已保存选择优先。
- B/Y 按层返回与单右手柄恢复；普通视频播放时可退出视频返回媒体库，扳机操作控件、握持移动画面。
- Emby 完整标题、符合条件的单片文件夹横图、竖幅演员卡和服务器支持的紧凑排序弹窗。
- 支持场景下沉浸文本／平面 PGS 字幕、照片放大镜／人像／空间照片及平面旋转视频的高效合成层显示。

- Alpha 透视画质与帧率调节、羽化／边缘收缩及全局模型尺寸选择；不支持新版路径的头显自动回退到眼缓冲 Alpha。
- 摇杆预选目标、回中提交跳转，独立目标时间及缓冲反馈；可自定义 360° 半圈转向和上下视频组合键。
- 面向观看位置的独立播放面板及联动媒体库布局，保留显式跟随开关。
- 按来源能力提供可选文件管理模式、多选删除、改名预览确认和同主名伴随文件联动，支持 115 Open 文件／文件夹改名。

- 兼容的完整左右立体鱼眼视频可手动选择片源自带 Alpha 遮罩，逐片记忆；与“AI 人像透视”分开控制。
- 记住主媒体库的观看距离，应用或系统回中时朝向当前视线。

- 视频、照片和目录收藏，支持返回来源目录、批量移除记录与撤销；不删除原始媒体。
- 播放记录可选全部／仅本地／不记录；收藏可用四位 PIN 加密保存，并配置自动锁定。
- 兼容磁盘及分区的 FAT32／exFAT／NTFS U 盘只读播放，提供停止本应用全部 U 盘访问的全局按钮。
- 有效源数据支持的空间媒体立体偏移与匹配拍摄视角。
- 无菜单时的手柄射线、静止隐藏和平面视频四角扳机缩放，可配置摇杆平面大小／沉浸缩放。

- 本地、SMB与网盘的跨目录字幕选择，记忆选择位置，独立分页并保留逐字幕同步设置。
- TIFF、Radiance HDR与OpenEXR照片／全景图，采用受限解码与显示色调映射，见[图片格式](docs/IMAGE_FORMATS.md)。
- 8K晨光天空背景，支持方向／亮度调节及自定义背景删除，不删除原始图片。
- 网盘目录按需分页与来源支持的排序，WebDAV复用已读取的目录快照。

- 全局音乐播放器、自建歌单、离线导入与MP3／OGG／WAV／FLAC／DTS支持，默认在视频播放时暂停音乐，也可开启同时播放并单独调节音乐音量。内置录音单独提供，见[音频资源说明](docs/AUDIO.md)。
- 记忆单片、单片循环、顺序及列表循环，支持来源可有限跨页接续。

- 19种语言离线文字字幕朗读、12种预设及可复用的自定义音色、最高1.8倍自动读速及逐视频设置；模型和预设载荷另行准备，见[模型范围](docs/MODELS.md)。
- 图片及单目360°拼图，支持独立存档、参考图、转腕旋转和完成特效。
- 影院银幕预设、1～50米距离及100%～3000%大小，可自动跟随调整或主动固定平面观看默认值。
- 逐音轨同步、头显系统媒体音量联动及逐视频轻声增强。
- 导入前拖动试听、音乐悬停快捷操作和多语言系统键盘搜索。

- 播放记录与逐片配置独立选择全部／仅本地／不记忆，分别清理；默认不因关闭历史而关闭逐片记忆。
- 照片头动空间立体／3D静态模式、全局照片观看偏好及视频／照片分别全局记忆的深度强度；Apple静态模式保留原生双眼画面。
- 从用户选择的合适媒体／音轨取样创建自定义音色，支持语音检测、裁剪、试听、改名／删除及默认音色管理；个人音色数据保留本地，不随源码公开。

- 兼容平面和沉浸视频可保存片源分辨率、最高质量JPEG截图（仍有损）；1倍速录像保存MKV，VR画中画使用有界SDR合成，并录入应用实际播放的声音（含朗读／音乐），导出MKV；受关键帧及片源限制，见[捕获说明](docs/CAPTURE.md)。

## 空间媒体与照片布局

- HEIC/HEIF原生立体空间照片与iPhone MV-HEVC空间视频；空间视频可使用支持的人物透视路径，空间照片输出sRGB，不宣称原生HDR。
- 两侧小图、1～3 行照片墙和记忆碎片，异步加载反馈、展开拖动及布局记忆。
- 普通平面照片人像透视、0～200%立体强度；原生立体/全景和多图总览不进入该人像路径。
- 平面视频、单图/人像及菜单的会话内头显跟随，独立环境透视开关；不宣称永久空间锚点或整面照片墙随头锁定。
- 视频双眼/左视角/右视角和逐片水平/垂直校正；单视角由双眼显示同一逻辑视角，不关闭另一块屏幕或改变头显IPD。
