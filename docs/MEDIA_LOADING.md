# 网络媒体加载反馈

SMB、DLNA、Emby/Jellyfin 及已连接网盘/WebDAV 的所有可打开媒体使用同一加载反馈，包括普通视频、图片、STRM 和蓝光 ISO。按有效播放来源判断：本地 STRM 指向网络媒体时也有网络反馈；直接打开本地文件不显示网络速度。

打开期间显示当前阶段、已等待秒数和可获得的读取速度：控制栏打开时用栏内状态区，隐藏时用独立小提示，不因普通缓冲自动唤出控制栏。阶段包括连接、读取媒体、读取光盘和准备播放。视频首帧出现后结束打开提示；播放中等待网络缓冲时重新显示。读取期间保留控制栏，用户主动关闭仍有效。

SMB、媒体服务器及网盘代理按照上游实际读到的媒体字节计算最近一秒读取速率；重读的范围计入实际传输量，不冒充文件完成百分比。直接 HTTP/HTTPS（包括 DLNA）使用 MPV 的 `cache-speed`，它是输入层最近一秒的字节读取速率：[MPV 官方属性说明](https://mpv.io/manual/stable/#properties)。图片按照输入流实际读到的字节计算。速度采用 KB/s、MB/s；连接尚未取得数据时只显示阶段和时间，测量可用后停读会显示零。元数据接口响应、缩略图预取和字幕不计入主视频速度；没有伪造进度，也没有增加完整视频下载。

视频格式、连接、解码及 HTTPS 证书错误主动显示简短原因。首次打开等待 60 秒、Seek/输出更新等待 30 秒、播放中等待缓冲 30 秒仍无进展会结束对应请求并显示超时；有实际媒体字节继续读入时延长等待期限，已等待秒数持续累计，避免慢速网盘被误判失败。用户暂停不触发缓冲超时。文件区提供展开图标，可恢复完整媒体库与来源侧栏并保留播放控制栏、文件夹及浏览位置；失败后打开文件夹也能恢复完整浏览。

原生 MPV/curl 使用应用默认信任管理器提供的公开 CA 证书，保留证书及主机名验证。独立 HTTP ISO 经 Android TLS/Range 代理读取，覆盖光盘预检与播放。Emby/Jellyfin 的 PlaybackInfo 可返回远程 HTTP 原文件，应用采用独立上游读取器，支持服务器指定的 RequiredHttpHeaders，不把保存的服务器 token 附加到远程站点；跨来源重定向只保留 User-Agent、Accept、Accept-Language，不转发认证、Cookie 或自定义请求头。远程源仍需支持 Range，受限或失效直链会明确报错。


主机与原生编译检查不等同于所有服务器／头显的实际播放验收。

摇杆先预选目标和累计跳转量，回中提交，匹配的新画面呈现后提示才淡出。播放失败自动弹出简短原因，可展开详情；关闭后可从控制栏重新打开。错误反馈不代表底层网络或解码故障都会自动修复。
