# 源码、构建与操作指南

源码发布范围、开发入口和详细操作由功能介绍页迁入此处。

## 公开范围与构建条件

公开仓库包含应用源码、必要资源、构建与模型修改脚本、第三方来源和测试。模型权重、编译依赖、签名密钥、个人媒体和研发记录不进入 Git。

**全新克隆尚不能在缺少外部工具链和匹配模型时直接生成 APK。** 当前默认抠像模型是本项目修改并蒸馏的 RVM；本次源码发布没有托管其权重，上游 checkpoint 不能直接替代。具体文件、SHA256、导入方式和复现边界见 [模型说明](MODELS.md)。本快照不宣称已经完成现有 APK 的完整对应源码交付。

不依赖模型和 Android SDK 的源码检查：

```powershell
python tools/Check-PublicSource.py
$env:GODOT_EXE = (Get-Command godot).Source
./tools/Test-Source.ps1
```

Android 构建需先完成 [环境准备](BUILD.md)，再导入自行取得且有权使用的版本匹配模型：

```powershell
$env:THRU3D_TOOL_ROOT = Join-Path $HOME '.cache/thru3d-toolchain'
./tools/Import-ModelAssets.ps1 -FromDirectory ./external-model-assets
./tools/Build-Player.ps1 -ToolRoot $env:THRU3D_TOOL_ROOT -UsePreparedModelAssets -XrVendor Quest
./tools/Build-Player.ps1 -ToolRoot $env:THRU3D_TOOL_ROOT -UsePreparedModelAssets -XrVendor Pico
./tools/Build-Player.ps1 -ToolRoot $env:THRU3D_TOOL_ROOT -UsePreparedModelAssets -XrVendor OpenXR
```

可重建输出放在忽略的 `build/output/`，短期数据放在 `tmp/`。正式发布归档、签名资料和个人备份使用持久目录，并始终排除于公开 Git。自行生成的签名不一定可以覆盖已有发行版。Quest/PICO 分别使用对应厂商导出预设；标准 OpenXR 目标要求设备具备兼容运行时，PICO/通用打包检查不等同于真机验证。运行所需的 MIT 手部 glTF 网格随源码保留，AI 权重不入 Git。

## 目录与操作

`app/godot` 包含场景、菜单、着色器和语言；`android` 包含 Kotlin 插件和 JVM 测试；`native` 包含 JNI 与推理/渲染；`tools` 包含构建和验证；`models` 只保存契约、哈希和许可；`third_party` 保存依赖来源与声明。

左 Menu 打开菜单，用手柄射线指向并按对应扳机选择。媒体库、设置、列表弹层及图片菜单中，摇杆只用于滚动并隔离播放快捷动作。普通视频控制条显示时仍可用摇杆快进/快退、音量和沉浸缩放；指针捕获期间屏蔽快捷动作，退出列表或结束捕获后须回中再触发。也支持手部指向和捏合。桌面模式用于开发预览。

右手 A 默认控制视频播放／暂停或收起展开照片，左手 X 打开媒体库。B/Y 逐层返回，先关闭弹层，再返回上一级文件夹；无播放时保留媒体库最外层，界面隐藏后可用右扳机或 B 重新打开。播放中先按弹窗、目录或捕获的上下文返回／取消；普通视频播放时按 B/Y 会保存已有进度、关闭视频并返回完整媒体库，控制栏隐藏时也有效。图片保留原返回行为，已配置的组合键仍优先。射线指向菜单外按扳机也可关闭。视频设置在播放条上方展开，照片设置保留整面板布局。全局“操作”页可点击绑定值选择按键、配置组合键及界面移动范围，并查看手势动画；冲突时确认互换或取消，保留返回和射线选择。3D 和音量图标单击调节、双击开关／静音。

左右握持键移动视频画面、界面或照片放大镜。视频中握持键移动平面屏幕或转动沉浸画面，普通扳机只操作控件及显隐播放条。握持配合同手摇杆↑/↓推远／拉近适用目标，扳机配合摇杆推拉仅保留用于平面图片。普通菜单保持直立，跟随模式才使用头显倾斜；应用居中及系统回正恢复默认菜单摆放，位置偏移只在本次运行记忆。播放中展开完整媒体库仍可用底部控制栏。

抠像质量、GPU 支持及持续性能取决于模型、设备和媒体；主机与打包测试不代表头显播放性能验收。技术细节见 [架构](ARCHITECTURE.md)、[测试](TESTING.md) 和 [贡献指南](../CONTRIBUTING.md)。

项目原创源码采用 **GPL-3.0-only**，完整文本见 [LICENSE](../LICENSE)。第三方组件及资源保留原许可；适用范围和二进制发行要求见 [许可说明](LICENSING.md)。

内嵌OpenList组件采用 **AGPL-3.0**；`cloud/openlist`包含Go适配源码，构建脚本和上游/依赖许可随源码保留。组合二进制发行还须履行适用的AGPL义务，详见许可说明。

视频控制栏外按手柄扳机仅关闭控制栏，该次按下期间的手部偏移不会拖动画面；时间线及滑条仍可拖动。视频设置默认显示播放页，调色及立体观看以条上弹窗打开；照片设置保留原面板布局。

视频 2D→3D 按文件独立记忆，新文件默认关闭；图片使用独立全局偏好。手动开启的视频人像透视不会带到下一次打开。外挂字幕优先同名，再尝试界面语言；手动／已保存选择（含关闭）优先于自动规则。

## 跳转、组合键与 Alpha 设置

摇杆先预选目标，明确回中后才提交跳转；默认左手20秒、右手10秒，长按累加，保留播放／暂停状态，匹配的新画面呈现后提示淡出。列表、设置或指针捕获会取消待提交目标，并保持快捷动作隔离。缓冲使用控制栏内状态或独立被动提示，不强制打开控制栏。

握持与扳机修饰键可按任意先后顺序使用；可选组合提供360°画面半圈转向及当前队列上下视频，不新增默认绑定。B/Y先处理弹窗、目录或取消捕获，普通视频观看／控制条中则关闭视频回完整媒体库；图片保持原返回行为。

Alpha 模型尺寸为256／320／384／512并全局保存，未保存偏好的帧率限制默认为30FPS。冷尺寸首次可能需约一分钟准备，播放中准备完成前保留当前尺寸；已缓存尺寸复用。羽化／边缘收缩可在播放器和媒体库设置中调整。新版Alpha已纳入0.10.0 Release发布范围，实际播放与抠像速度仍受头显、片源及所选设置影响。

文件管理须主动开启并受来源能力限制；删除前确认、改名前预览，同名伴随文件按主名完全相同匹配，文件夹改名不递归。115 Open不等于旧Cookie115也支持改名；写入结果不明时先核实，不自动重复写入。

头显／运行时不支持新版Alpha透视时，自动回退到眼缓冲Alpha。

## 片源遮罩与媒体库封面

播放模式面板的鱼眼角度行右侧提供“使用片源自带的 Alpha 遮罩”。仅兼容的完整左右立体鱼眼视频可开启；上下立体、半宽左右立体及空间视频不使用此开关。开启后使用片源打包遮罩并停止 AI 实时抠像，播放栏“AI 人像透视”入口置灰。选择按视频保存，手动关闭也优先于文件名中的 `_alpha` 标记；切换到其他投影会关闭当前片源遮罩。

支持的合成层视频播放后也可自动生成媒体库封面，沿用黑帧重试；立体内容截取左眼画面，并按片源方向处理。截取失败不会阻止播放。

115 Open 删除文件夹不再先完整扫描子树或在确认后重复扫描，减少等待；仍核对目标身份、类型与权限，并在结果不明时验证状态，不自动重复删除。此优化不改变本地／SMB 删除规则，也不代表旧 Cookie 版 115 或其他网盘具有相同表现。

## 收藏、隐私与 U 盘播放

首页可在最近播放和收藏之间切换，播放时也可直接收藏。支持的条目可返回来源目录；勾选、批量移除和短时撤销只管理记录，不删除原文件。

播放记录可选全部、仅本地或不记录；清理网络或全部记录保留账号连接与主动收藏。收藏可设置四位 PIN 加密保存，手动锁定并选择自动锁定策略；锁定时隐藏内容并关闭受保护播放。这些属于本应用隐私控制，短 PIN 不保证抵御离线猜测，也不限制通过其他方式访问原文件。

兼容的 U 盘可只读浏览 FAT32、exFAT 和 NTFS，支持符合条件的分区及同目录字幕；系统挂载卷可能需要只读文件夹授权。媒体库上方全局停止按钮释放本应用对全部 U 盘来源的播放与读取，不代表系统卸载或断电。旧原始 USB 会话收藏不保证在拔插后自动恢复定位。

## 空间媒体信息与手柄反馈

具有有效源信息的空间视频可应用推荐立体偏移，并逐片记忆；带有效拍摄信息的空间视频和照片可匹配拍摄视角。不宣称完整 Apple 空间呈现或真实尺度还原。

无菜单时移动手柄或按键可唤醒射线和落点，静止反馈随控制栏隐藏。平面视频可通过四角扳机等比缩放；默认右摇杆上下调整平面大小或沉浸缩放，保留已保存的自定义映射。照片转 3D 等待立体结果就绪后切换，支持的视频 2D 转 3D 继续显示平面 PGS 字幕。

## 字幕文件与网盘分页

字幕选择器支持本地、SMB和兼容网盘的跨目录选择，记忆位置并使用独立页偏移；选择后恢复媒体浏览上下文，同名字幕自动发现仍是独立的有界操作。字幕同步偏移按视频内的每条轨道／外挂文件独立记忆，手动选择优先。

原生网盘按需加载有限目录页并按来源能力排序；WebDAV复用完整获取的目录快照，不代表服务端分页。115保留按账号隔离的父目录身份用于播放准备，管理写入前实时校验父目录和目标身份；减少重复查询，不承诺固定网络时延或绕过权限。

视频深度使用匹配的364×210延后上采样模型和调整后的时序平滑，独立照片模型仍为518×518。Alpha FPS按实际绘制计数，masked-only实验已撤回。自0.12.0起普通构建默认接入字幕朗读，模型及音色载荷需另行准备，见[模型要求](MODELS.md)。0.12.1新视频默认关闭朗读并保留画面字幕，逐视频保存语言、音色等偏好；平面默认值跟随最新调整，除非主动固定。正式Release支持照片／单目360°拼图、独立存档、参考视图及完成特效。

## 音乐与视频播放模式

首页和看图界面共用单路音乐播放器；离线导入完整保存后无需来源在线，移除应用副本不删除原文件。支持自建歌单、排序及顺序／列表循环／单曲循环／随机播放，默认进入视频自动暂停音乐，可开启同时播放并独立调节音乐音量。内置曲目音频不在公开源码中，见[音频资源](AUDIO.md)。视频独立提供单片、单片循环、顺序和列表循环；来源支持时跨页接续，不做全目录预扫或无限坏文件重试。115主视频准备与伴随字幕/音轨分开，播放优先。

## 0.12.2 源码范围

`privacy/history`控制最近播放、续播与缩略图，`privacy/file_settings`独立控制逐片观看、音字幕选择／同步、朗读及轻声增强；旧版关闭历史时，升级后的逐片记忆仍默认全部。两类分别关闭和清理，关闭开关不自动删除既有数据；受保护收藏的加密／锁定边界保留。

朗读提供19种文字语言、12种预设音色来源及本地创建的自定义音色，支持试听、改名／删除和默认音色；新视频仍默认关闭朗读。试听流式准备／缓存、局部节奏及电平处理复用生产路径，另需匹配参考编码器载荷。照片观看模式／强度全局记忆，视频／照片深度强度分别全局记忆，视频模式开关仍按文件保存；空间浮雕按实际物理显示尺寸计算。

巨幕影院(测试)在Debug／Release均可用，[完整场景资源须另行生成](EXPERIMENTAL_CINEMA.md)；在线全景入口继续隐藏。源码不含个人音色及模型载荷。

## 0.12.3 捕获与网络读取

兼容沉浸视频支持[原始截图和无损片段](CAPTURE.md)，保留排布字段与独立状态／停止入口；当前Android导出MKV，边界受关键帧限制，不公开实际导出媒体或个人夹具。

原声取样使用独立有界读取、已验证的115下载票据共享、临时错误／过期链接恢复及及时释放连接；DLNA外挂字幕兼容首条字幕之前的候选定位。不据此保证全部来源／片源或修复任意旧播放记录。

## 画中画、腕表与目录续览

控制栏可打开[画中画及静态图片窗口](PICTURE_IN_PICTURE.md)，也可切换徒手腕表。目录位置按来源／账号、目录及全部／视频／图片筛选分别记忆，默认开启。续览统一跟随历史隐私：全部可跨重启，仅本地时网络位置仅内存，不记录时全部仅本次运行有效；清除历史同时清理位置，后来开启历史不会补写高隐私期间位置。关闭续览后普通重新进入从顶部开始，显式返回上级仍保留上下文。目录排序和按网盘能力的页数设置独立保存，全部载入须显式选择。

## 0.13.3 接收、取样与菜单

手动开启[DLNA视频接收](DLNA_CASTING.md)后接收兼容局域网投屏；替换当前媒体需确认，投屏结束后可选择返回原媒体，此功能不镜像手机屏幕。添加自定义声音改为选择媒体／音轨、有界扫描语音候选、行内裁剪及试听，无需字幕；编辑声音或输入口令时延后投屏提示。

影院厅灯在底栏控制，影片驱动溢光与瞄准椅子入座使用重新生成的完整资源。服务器背景设置位于服务器浏览器，渲染倍率使用四项行内选择。视频深度强度上限100%、默认50%，照片保留独立范围。
